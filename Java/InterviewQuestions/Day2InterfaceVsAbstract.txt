1. ReferenceType and ObjectType?
The reference type determines what methods are accessible at compile time, while the actual object type determines which overridden implementation executes at runtime.

2. Explain when and why you would choose an interface versus an abstract class?

I would choose interface only when contracts needs to be defined and also when class needs multiple inheritance for different contracts, while I would use an abstract class when the subclasses have a strong common relationship and I want to share common state, behavior, or partially implemented functionality between them.


3. Why do you think Java allows multiple interfaces but doesn't allow multiple class inheritance?
Java allows a class to implement multiple interfaces because interfaces primarily define contracts or capabilities, allowing a class to combine different behaviors. Java doesn't allow multiple class inheritance because inheriting concrete implementations from multiple parents can create ambiguity about which implementation should be used. This avoids problems such as the diamond inheritance problem.

With interfaces traditionally defining abstract contracts, there is no competing implementation to choose from.
